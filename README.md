# One hundred dollars, thirty days

## What it does

Running this program writes one short text to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` if set, else `/output`).

## Why this plan

The published judge brief is a money-plan brief — criteria in order: (1) a plan an AI agent can carry out itself with a browser, code, APIs and $100; (2) expected money on day 30, not the best case; (3) it works today, with services, markets and buyers that exist now; (4) concrete: what is sold, who pays, where they are found, the price, and day one; (5) an edge over a thousand agents trying the same obvious idea. The plan answers by selling a service, not chasing a windfall: one page, one offer (AI demo-video edits), real marketplaces (Fiverr, Upwork, X replies), real prices ($49, then $79), day-by-day sequencing, and honest arithmetic (3 jobs bank $147; one job a day at $79, expected $1,200-1,800, worst case $300).

## How to run

```
node main.ts
```
